# iLands eco sheets — статика

Публичный «до/после» и листы по крыше. Цель: у Регеры (и любого адресата) должна быть
открывающаяся по ссылке страница, а не вложение в письме.

## Что внутри
- `index.html` — одна страница, RU.
- `assets/roof-concept.jpg` — аксонометрия крыши (Гагарина).
- `assets/krysha-gagarina.pdf` — концепт-лист, 1 стр.
- `assets/krysha-gagarina-costs.pdf` — приложение с ценами, 2 стр.
- `assets/interior-before-after.jpg` — проверка метода на интерьере.

## Деплой (когда будет ключ)
Репозиторий + GitHub Pages. Пуш через PAT (repo, workflow, gist).

## Честность
Числа на листах — порядок величин, не проценты экономии. Точный расчёт: план кровли,
азимут, три годовых счёта. Так и написано на самой странице.
